* A TrafficLight enum-on belül hozz létre egy nextLight() metódust, ami megvalósítja a következőt:
* main:
```
public class TrafficSystem {
    public static void main(String[] args) {
        // Kezdőállapot beállítása
        TrafficLight currentLight = TrafficLight.RED;

        System.out.println("--- Lámpa ciklus szimuláció ---");
        
        // Szimulálunk 5 lámpaváltást
        for (int i = 1; i <= 5; i++) {
            System.out.println("Lépés " + i + ": A lámpa jelenleg " + currentLight);
            // Lekérjük a következő színt, és felülírjuk vele a jelenlegit
            currentLight = currentLight.nextLight();
        }
    }

}
```
* kimenet:
```
--- Lámpa ciklus szimuláció ---
Lépés 1: A lámpa jelenleg RED
Lépés 2: A lámpa jelenleg GREEN
Lépés 3: A lámpa jelenleg YELLOW
Lépés 4: A lámpa jelenleg RED
Lépés 5: A lámpa jelenleg GREEN
```
***Ez a feladat bemutatja, hogy az enumoknak saját logikájuk is lehet. A "piros lámpa" önmaga tudja a szabályt, hogy utána a "zöldnek" kell következnie, így az ezt használó külső kód sokkal rövidebb és tisztább lesz.***
