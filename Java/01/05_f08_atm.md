### Bankautomata szimulátor (Vezérlési szerkezetek: Switch, While, Metódusok) 
Feladat: Készíts egy interaktív, menüvezérelt bankautomatát!
Lépések:
* Hozz léter egy atm nevű package-t, a továbbiakban ebben dolgozz!
* A Main osztályban deklarálj egy balance (egyenleg) változót (pl. double). És adj neki egy kezdőértéket! 
* Írj egy while ciklust, amely addig fut, amíg egy isRunning boolean változó igaz.
* A cikluson belül írj ki egy menüt: 1. Egyenleg lekérdezése, 2. Befizetés, 3. Kifizetés, 4. Kilépés.
* Használj Scanner-t a választás beolvasására, és egy switch (vagy if-else) szerkezetet a megfelelő művelet kiválasztására!
  - Scanner input = new Scanner(System.in);
  - int choice = input.nextInt();
  - double depositAmount = input.nextDouble();
* A kifizetés és befizetés logikáját (pl. ellenőrzés, hogy van-e elég pénz a kifizetéshez) szervezd ki külön statikus metódusokba, amelyek megkapják az aktuális egyenleget és az összeget, majd visszatérnek (return) az új egyenleggel!
* Kivételkezeléssel nem kell foglalkoznod.
