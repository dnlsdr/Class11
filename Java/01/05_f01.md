Készíts egy metódust a felhasználó köszöntésére!

**Lépések:**

1. Hozz létre egy `Greeter` nevű osztályt!
2. A `Greeter` osztályon belül hozz létre egy paraméter nélküli, `greet` nevű statikus (`static`) metódust!
3. A `greet` metódusban írasd ki: „Hello, User!”!
4. Adj hozzá egy `main` metódust!
5. A `main` metódusban hívd meg a `greet` metódust!
