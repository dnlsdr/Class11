Feladat: Access Modifierek – Public, Protected, Default, Private

Hozz létre egy class-t különböző access modifierrel ellátott mezőkkel (fields), és próbáld meg elérni őket egy másik class-ból!

**Lépések:**

1. Hozz létre egy `Person` nevű class-t!
2. A `Person` class-on belül hozz létre mezőket (pl. `name`, `age`, `address`, `ssn`) különböző access modifier-ekkel: `public`, `protected`, `private`, valamint egyet módosító nélkül (`default`)!
3. Hozz létre egy másik, `Main` nevű class-t!
4. A `Main` class `main` method-jában hozz létre egy instance-ot a `Person` class-ból, és próbáld meg elérni a mezőit!
5. Melyik mezőhöz férsz hozzá? Melyik mezőkhöz nem férsz hozzá?
