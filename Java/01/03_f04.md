Írasd ki az első `n` páros számot `while` ciklus segítségével!

Használj `while` ciklust az első `n` darab páros szám kiíratására.

**Lépések:**

1. Deklarálj egy `int` típusú `n` nevű változót, valamint egy `int` típusú `counter` nevű változót 0 kezdőértékkel inicializálva!
2. Rendelj egy értéket az `n` változóhoz!
3. Használj `while` ciklust az első N darab páros szám kiíratására!
