Hozzunk létre egy csomag- és osztályszerkezetet egy termékinventory (készletnyilvántartó) alkalmazáshoz. Létre fogsz hozni egy `Product`, egy `Inventory` és egy `Warehouse` osztályt néhány mezővel, valamint egy `Main` osztályt a megvalósításod teszteléséhez.

1. Hozz létre egy `inventory` nevű csomagot!
2. Az `inventory` csomagon belül hozd létre a következő osztályokat a megadott mezőkkel (adattagokkal):
**Product:**
* `productId` (int)
* `productName` (String)
* `price` (double)


**Inventory:**
* `product` (Product)
* `quantity` (int)


**Warehouse:**
* `warehouseId` (int)
* `warehouseName` (String)
* `inventories` (String, később majd `Inventory` objektumok `ArrayList`-jét fogjuk itt létrehozni)


3. Hozz létre egy `main` nevű csomagot!
4. A `main` csomagon belül hozz létre egy `Main` nevű osztályt egy `main` metódussal!
5. Add hozzá a szükséges importálásokat a `Main` osztályhoz, hogy elérd a `Product`, `Inventory` és `Warehouse` osztályokat az `inventory` csomagból. Ezeknek a `package` (csomagdeklaráció) sor alá kell kerülniük:
```java
import inventory.Product;
import inventory.Inventory;
import inventory.Warehouse;

```


6. A `main` metódusban hozz létre egy `Product`, egy `Inventory` és egy `Warehouse` objektumot, és adj meg valamilyen értéket a mezőiknek!
7. A megoldásod ellenőrzéséhez írasd ki a mezők összes értékét a konzolra!
