Készíts egy metódust, amely két egész számot vár bemeneti paraméterként, és kiírja az összegüket!

**Lépések:**

1. Hozz létre egy `Adder` nevű osztályt!
2. Az `Adder` osztályon belül hozz létre egy `add` nevű statikus (`static`) metódust, amely két `int` típusú paramétert vár!
3. Az `add` metódusban számítsd ki a két bemeneti paraméter összegét, és írasd ki az eredményt!
4. Adj hozzá egy `main` metódust!
5. A `main` metódusban hívd meg az `add` metódust két egész számmal mint argumentummal!
