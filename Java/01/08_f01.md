* Készíts egy enum_gyakorlás nevű package-t, ebben dolgozz!
* Készíts egy UserRole enumot (GUEST, USER, ADMIN).
* Írj egy User osztályt, aminek a következő mezői és metódusai vannak:
  - private String username;
  - private UserRole role; // A mező típusa maga az enum
  - canEditContent(), ami csak akkor tér vissza true értékkel, ha a felhasználó ADMIN.

* main metódusban az implementálás:
```
        User guest = new User("Látogató_01", UserRole.GUEST);
        User admin = new User("SzuperAdmin", UserRole.ADMIN);

        System.out.println(guest.getUsername() + " szerkeszthet? " + guest.canEditContent());
        System.out.println(admin.getUsername() + " szerkeszthet? " + admin.canEditContent());
        // HIBÁS, nem fordulna le:
        // User hacker = new User("Hacker", "SUPERADMIN"); // Hiba: Nincs ilyen enum típus!
```
* várható kimenet:
```
Látogató_01 szerkeszthet? false
SzuperAdmin szerkeszthet? true
```
