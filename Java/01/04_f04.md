Feladat: Primitív adattípus átadása egy metódusnak

Adj át egy primitív adattípust egy metódusnak, módosítsd azt, majd írasd ki az értéket a metódushívás előtt és után!

**Lépések:**

1. Hozz létre egy `Main` nevű osztályt, és adj hozzá egy `main` metódust!
2. Deklarálj egy `int` típusú `number` nevű változót a `main` metódusban!
3. Rendelj egy értéket a `number` változóhoz!
4. Írasd ki a `number` értékét!
5. Ugyanebben az osztályban hozz létre egy `modifyNumber` nevű metódust! A `modifyNumber` metódusban módosítsd a paraméter értékét az alábbi módon:
```java
public static void modifyNumber(int num) {
    num = num * 2;
}

```


6. Hívd meg a `modifyNumber` metódust, és add át neki paraméterként a `number` változót!
7. Írasd ki a `number` értékét a metódushívás után!
8. Milyen eredményre számítasz?
