* Készíts egy CoffeeSize enumot (SMALL, MEDIUM, LARGE). 
Minden mérethez ments el egy alapárat és egy űrtartalmat (pl. MEDIUM(850, 300)). 
Írj egy programot, ami kiírja az étlapot az enum segítségével.
* main metódus:
```
    public static void main(String[] args) {
        System.out.println("--- Kávézó Étlap ---");
        // A .values() metódus visszaadja az összes enum konstanst egy tömbben
        for (CoffeeSize size : CoffeeSize.values()) {
            System.out.println("Méret: " + size.name() +
                    " | Űrtartalom: " + size.getVolumeMl() + " ml" +
                    " | Ár: " + size.getPrice() + " Ft");
        }
    }
```
* Várható kimenet:
```
--- Kávézó Étlap ---
Méret: SMALL | Űrtartalom: 200 ml | Ár: 650 Ft
Méret: MEDIUM | Űrtartalom: 300 ml | Ár: 850 Ft
Méret: LARGE | Űrtartalom: 500 ml | Ár: 1050 Ft
```
***Itt az enum már nemcsak egy név, hanem önálló adatokat is hordoz. Minden mérethez garantáltan tartozik egy ár és egy űrtartalom.***
