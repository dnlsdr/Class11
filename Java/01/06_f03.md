Feladat: Javítsd a hibát!

Javítsd ki a felmerülő problémát, amikor egy alapértelmezett (default) hozzáférési módosítónak valójában protected-nek kellene lennie!

**Lépések:**

1. Hozz létre egy `animals` nevű csomagot (package)!
2. Az `animals` csomagon belül hozz létre egy `Animal` nevű osztályt!
3. Az `Animal` osztályon belül hozz létre egy `species` nevű mezőt alapértelmezett (`default`) hozzáférési módosítóval!
4. Hozz létre egy másik, `main` nevű csomagot! Ezt az `animals` csomaggal azonos szintre helyezd!
5. A `main` csomagban hozz létre egy `Dog` nevű osztályt, amely kiterjeszti (örökli) az `Animal` osztályt!
```
public class Dog extends Animal()
```
6. A `Dog` osztályhoz adj hozzá egy `printSpecies` nevű metódust, amely kiírja a `species` értékét! A piros hullámos vonalat egyelőre hagyd figyelmen kívül!
7. A `main` csomagon belül hozz létre egy `Main` nevű osztályt!
8. A `Main` osztály `main` metódusában hozz létre egy példányt a `Dog` osztályból, és hívd meg a `printSpecies` metódust!
9. Javítsd a problémát a `species` mező hozzáférési módosítójának `protected`-re változtatásával!
10. Létezett volna más mód is a hiba elhárítására?
