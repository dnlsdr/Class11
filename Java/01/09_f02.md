### Futárszolgálat Csomagautomata

**Gyakorolt elvek:**

* Objektum kompozíció (egy objektum egy másik objektumot tartalmaz mezőként) és Enum használat.


* A "Pass by Value" mechanika objektumokon: egy metódus közvetlenül módosítja a kapott objektum belső állapotát a másolt memóriacímen keresztül


* ciklus és `switch` szerkezet interaktív menühöz (`Scanner` használatával).



**Feladat:** Szimuláld egy csomagautomata működését, ahol a futár vagy az ügyfél módosíthatja egy csomag állapotát!

**Lépések:**

1. Hozz létre egy `delivery` nevű package-t!


2. Hozz létre egy `PackageStatus` enumot az alábbi értékekkel: `AT_SENDER`, `IN_TRANSIT`, `IN_LOCKER`, `DELIVERED`.


3. Hozz létre egy `Parcel` (csomag) osztályt `public String trackingCode`, `public int weightGrams` és `public PackageStatus status` mezőkkel!


4. Hozz létre egy `CourierSystem` osztályt, benne egy `public static void advanceStatus(Parcel p)` metódussal!


* A metódus egy `switch` szerkezettel vizsgálja meg a kapott csomag `p.status` mezőjét, és léptesse a következő állapotba (`AT_SENDER` -> `IN_TRANSIT` -> `IN_LOCKER` -> `DELIVERED`)! Ha már `DELIVERED`, írja ki, hogy a csomag már célba ért!



5. A `Main` osztályban példányosíts egy `Parcel` objektumot (`"HU-9988"`, `1200` gramm, `PackageStatus.AT_SENDER` alapállapottal)!


6. Indíts egy ciklust, amely minden körben kiírja  csomag aktuális állapotát, majd egy menüt kínál fel (`Scanner`-rel beolvasva):


* `1`: Állapot léptetése (meghívja az `advanceStatus` metódust).


* `2`: Csomag súlyának módosítása (bekér egy új súlyt, és átírja a `weightGrams` mezőt).
* `0`: Kilépés.
* A ciklus addig fusson, amíg a felhasználó `0`-t nem nyom!





**Várható output (példa interakció):**

```text
=== Csomagkövetés: HU-9988 (1200g) | Státusz: AT_SENDER ===
1 - Státusz léptetése | 2 - Súly módosítása | 0 - Kilépés
Választás: 1
-> Státusz frissítve!

=== Csomagkövetés: HU-9988 (1200g) | Státusz: IN_TRANSIT ===
1 - Státusz léptetése | 2 - Súly módosítása | 0 - Kilépés
Választás: 1
-> Státusz frissítve!

=== Csomagkövetés: HU-9988 (1200g) | Státusz: IN_LOCKER ===
1 - Státusz léptetése | 2 - Súly módosítása | 0 - Kilépés
Választás: 0
Rendszer leállítva.

```
